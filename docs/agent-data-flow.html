Prompt context

Configured instructions and source fragments are loaded each turn. This is harness guidance, not conversation history.

Session history

Prior committed exchanges for the same session are included in the prompt. The current transcript is committed when the turn finishes.

Persistent memory

Relevant knowledge is recalled separately from the transcript. A candidate note may be persisted for future retrieval.
